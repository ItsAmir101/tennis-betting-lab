## GitHub files
Upload all four files to the same repository:
- `app.py`
- `requirements.txt`
- `2026-atp-season.csv`
- `2026-wta-season.csv`

## Streamlit
Set the main file to `app.py`.

The app no longer depends on Jeff Sackmann raw GitHub URLs, so the previous 404 error is avoided.

## Current data available
The supplied CSVs include:
- player names and IDs
- ranking/points
- tournament/round/surface
- winner/result
- sets
- match-winner odds
- aces
- double faults
- service points won %
- return points won %
- break-point conversion %
- break points saved %

They do not include shot-by-shot net touches or unforced-error counts.
